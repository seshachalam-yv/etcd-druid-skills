# Out-of-Scope Knowledge Base

This directory records design decisions that were explicitly rejected for etcd-druid. Its purpose is to prevent re-litigation of previously decided questions.

## Structure

Each file represents one rejected proposal with:

- **Title** — The proposal that was considered
- **Context** — Why the question came up
- **Decision** — Rejected (with date or era if known)
- **Reasoning** — Why it was rejected
- **Prior discussions** — Links to issues, PRs, or conversations where this was discussed

## Usage

Before proposing an architectural change, check this directory to see if the idea has already been evaluated and rejected. If circumstances have materially changed, reference the original rejection and explain what is different now.
