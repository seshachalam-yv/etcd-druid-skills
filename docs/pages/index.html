Planning & Execution
📋 plan
Reads the issue, explores codebase & past PRs, proposes 2-3 approaches, writes a structured plan. Gate 1 blocks code until you approve.
/etcd-druid:plan
⚡ implement
Creates isolated worktree, runs per-task subagent loop with spec-review + code-review, verifies CI. Gate 2 blocks push.
/etcd-druid:implement
Domain-Specific
🔧 api-change
CEL validation (field + cross-field), kubebuilder markers, two-commit generate workflow, CRD integration tests.
/etcd-druid:api-change
🧪 tdd
Red-Green-Refactor per repo. Correct framework: Go native for druid/wrapper, Ginkgo v2 for backup-restore.
/etcd-druid:tdd
🔍 debug
6-phase root cause analysis. Delve debugger, per-repo log analysis (logr/logrus/zap), build failure triage.
/etcd-druid:debug
🌐 e2e
KIND cluster setup, custom sidecar image builds, IMAGEVECTOR_OVERWRITE, pre-PR CI validation.
/etcd-druid:e2e
