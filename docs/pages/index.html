How it works
Agentic workflow.
Not autocomplete.

Every task follows a research-first approach. The plugin reads issues, studies past PRs, and builds a plan — then waits for you.

Capabilities
9 specialized skills.

Each encodes deep domain knowledge. Click any card for details.

Planning & Execution
📋 plan
Reads the issue, explores codebase & past PRs, proposes 2-3 approaches, writes a structured plan. Gate 1 blocks code until you approve.
/etcd-druid:plan
⚡ implement
Creates isolated worktree, runs per-task subagent loop with spec-review + code-review, verifies CI. Gate 2 blocks push.
/etcd-druid:implement
Domain-Specific
🔧 api-change
CEL validation (field + cross-field), kubebuilder markers, two-commit generate workflow, CRD integration tests.
/etcd-druid:api-change
🧪 tdd
Red-Green-Refactor per repo. Correct framework: Go native for druid/wrapper, Ginkgo v2 for backup-restore.
/etcd-druid:tdd
🔍 debug
6-phase root cause analysis. Delve debugger, per-repo log analysis (logr/logrus/zap), build failure triage.
/etcd-druid:debug
🌐 e2e
KIND cluster setup, custom sidecar image builds, IMAGEVECTOR_OVERWRITE, pre-PR CI validation.
/etcd-druid:e2e
Quality & Reference
✅ review
10-step checklist with 15 known footguns. Prow label validation, release note format, correct merge method.
/etcd-druid:review
📖 reference
Quick lookup: make targets, file paths, feature gates, CLI flags, git workflow, cherry-pick process.
/etcd-druid:reference
💡 observations
Triage plugin self-improvement findings. Pre-verifies against current files. Raise PR, skip, or dismiss.
/etcd-druid:observations
Self-improving
The plugin gets
better every session.

Every session is evaluated asynchronously. When a gap is found — a wrong claim, a missing footgun, a stale flag — it's captured as a structured observation. You decide what happens next.

How It Works

Auto-capture
Session ends → hook captures gaps automatically
Next session → observations are pre-verified against current files
Stale items auto-resolved (the fix is already in)
Verified gaps presented with evidence
You choose: R raise PR · S skip · D dismiss
PR raised only on explicit R choice

What Gets Captured

Evidence-based
Wrong claim
Plugin said "use make revendor" for etcd-druid — it's actually "make tidy"
Missing footgun
New CEL validation gotcha not encoded in review skill
Stale flag
Feature gate was promoted from alpha to GA — skill still says alpha
User correction
"No, the test should use Ginkgo v2 here, not Go native"
